# The Daily Edit — Blog Website

A responsive frontend blog project built with HTML, CSS, and JavaScript.

## Features
- Responsive layout for mobile, tablet, and desktop
- Article search and category filters
- Interactive article reading panels
- Mobile navigation menu
- Newsletter form demo (does not collect or send email)
- Accessible labels and keyboard support

## Run locally
Open `daily_edit_blog.html` in a browser.

## Publish with GitHub Pages
1. Upload the HTML file to the root of your GitHub repository.
2. Rename it to `index.html` in the repository (or upload it as `index.html`).
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, branch `main`, folder `/(root)`, then save.
5. Wait for deployment and open the published URL shown on the Pages screen.

## Important
This is a frontend internship/demo project. It does not include a database, user login, server-side publishing, or a working newsletter backend. Article content is example content and can be edited in the HTML file.
